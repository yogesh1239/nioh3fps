## How

- **F7b inline +0x614 reads**: every `mov reg,[rip+0x4759910]` (clock global) followed within 40 insns by `[reg+0x614]` before `reg` is redefined or control leaves. 56 reads total; the 2 inside GetFps/GetTimeStep are covered by the retaddr_hist rows, leaving 54 inline reads in 53 functions.
- **F9 consumers**: direct calls in `0x39e4e4` after `0x39e543` whose xmm0-3 args are loaded from xmm6/xmm7 (dt) since the previous call: 25 calls.
- **Containing function**: `.pdata` entry, following `UNW_FLAG_CHAININFO` to the primary entry; leaf functions without `.pdata` start after the preceding `ret`/int3 padding.
- **Hookable** = (a) a model of MinHook 1.3.3 `CreateTrampolineFunction` accepts the prologue (whole instructions >= 5 B; rip-relative, call/jmp/jcc rel are relocated; VEX, LOOP/JRCXZ, int3 rejected; < 5 B functions need padding after or above) and (b) nothing references fn+1..fn+4: rel32 and rip-relative disp32 (whole .text, verified by decoding), rel8 within +-0x82, RVA32 values (jump tables) and VA64 pointers in .text/.rdata/.data/_RDATA.
- **hook_rva**: the function itself, or the first hookable direct caller (by RVA) when not hookable.
- **aob / aob_offset**: rule: `aob` matches exactly once in the whole mapped image, at `hook_rva + aob_offset` (hook = match - aob_offset). Built from whole instructions, >= 16 B, starting at `hook_rva` (`aob_offset` = `0x0`) unless that start is not unique, then at the first unique instruction inside the function or its chained fragments. rel32 branch targets, rip-relative disp32 and base-relocated bytes are `??`. Asserted on every run.
- **prologue_bytes_hex**: the exact bytes at `hook_rva` covering the instructions MinHook relocates (>= 5 B); asserted against the image.
- **sites.csv**: prefilled from `tools/review/rev-sites/sites_classified.csv` plus the new sites below; `class=unknown` except P2 `0x39e526` (`scale`, proven statically in F9/F9c/G1). `caller_chain` is the documented chain where one exists, else up to 3 direct callers of the containing function. `hits_per_s` is filled from S1 logs.
